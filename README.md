# Proyectos VII Retrofit Fresadora
Proyecto Restrofit Fresadora CNC 

Integrantes:
Alfredo Emilio Vázquez Mata - Líder del proyecto / Control CNC
Marco Antonio Meza Eulloqui - Gestión de recursos
Carlos Gustavo Zamudio Robertos - Diseño mecánico
Denzel Guillermo Chuc Chuc - Sistema eléctrico y seguridad 

El proyecto consiste en la modernización (retrofit) de una fresadora Bridgeport convencional disponible en el taller de
metales de la universidad, con el propósito de incorporar control CNC aprovechando la estructura existente y los
recursos disponibles. Además de la automatización de los movimientos, el proyecto contempla la instalación de cuatro
puntos de anclaje para reducir el movimiento o tambaleo observado durante la operación de la máquina.
